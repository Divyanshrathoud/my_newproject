Upload index.html, style.css and app.js together into the folder containing your live index.html. Replace all three old files. Do not upload this enclosing folder as a nested folder. Wait for deployment, then hard-refresh the website.

No build command or Python server is required for this static edition. Music search uses the iTunes JSONP API and requires internet access. Audio is preview-only. Playlists are stored locally in this browser, not synced between devices.
